# publictest

A test repository for n8n workflow integration with GitHub releases.

## Installation

```bash
npm install
```

## Usage

```js
const { capitalize, parseDate } = require('./utils');

console.log(capitalize('hello world'));  // Hello world
console.log(parseDate('2026-04-29T10:00:00Z'));  // 29 April 2026
```

## Configuration

Edit `config.json` to adjust application settings.
